# Veridev - приучи агентов к дисциплине

Официальный лендинг проекта [Veridev](https://veridev.tech) — инструмента для AI-валидации кода и архитектуры.

## О проекте
Veridev меняет парадигму генерации кода: вместо хаотичного вывода нейросетей мы внедряем строгий пайплайн "Контракт → Тесты → Валидированный код". 

Этот репозиторий содержит исходный код статического лендинга, развернутого через GitHub Pages.

## Стек
- HTML5 / CSS3 (без тяжелых фреймворков для максимальной скорости)
- GitHub Pages (хостинг)
- Formspree (сбор заявок)
- Яндекс.Метрика (аналитика)
